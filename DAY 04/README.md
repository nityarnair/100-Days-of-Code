# Day 4 - Rock Paper Scissors ✊📄✂️

This is my **Day 4** project.

## What it does

- Lets the player choose **Rock**, **Paper**, or **Scissors**.
- Randomly generates the computer's choice.
- Compares both choices to determine the winner.
- Displays whether the player **wins, loses, or draws**.

## Skills Practiced

- Random module (`random.randint()` or `random.choice()`)
- Lists
- Conditional statements (`if`, `elif`, `else`)
- Nested conditions
- User input
- Basic game logic
