# Day 5 - Password Generator 🔐

This is my **Day 5** project.

## What it does

- Generates a secure random password.
- Lets the user choose the number of **letters**, **symbols**, and **numbers**.
- Randomly shuffles the characters for a stronger password.
- Displays the final generated password.

## Skills Practiced

- Lists
- Loops (`for`)
- Random module 
- String manipulation
- User input
- Variables and list operations
